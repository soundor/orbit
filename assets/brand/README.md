# Soundor Orbit brand assets

The official Soundor Orbit logo, in every variant. The files are the sources:
the text is outlined to paths, so no font is needed. See
[LICENSE.md](LICENSE.md) for how they may be used, and the
[Soundor Brand Guidelines](https://soundor.dev/brand).

| File                                                     | Use                                                           |
| -------------------------------------------------------- | ------------------------------------------------------------- |
| `soundor-orbit-logo.svg`                                 | Icon and name, on light backgrounds (32–64 px tall)           |
| `soundor-orbit-logo-on-dark.svg`                         | Icon and name, on dark backgrounds                            |
| `soundor-orbit-icon.svg`                                 | Dark tile, on light backgrounds                               |
| `soundor-orbit-icon-on-dark.svg`                         | Light tile, on dark backgrounds                               |
| `soundor-orbit-logo-mono-black.svg`, `-mono-white.svg`   | One colour (print, emboss)                                    |
| `soundor-orbit-icon-mono-black.svg`, `-mono-white.svg`   | One colour, symbol knocked out                                |
| `soundor-orbit-icon-maskable.svg`, `-maskable-light.svg` | Full-bleed square with a safe zone (PWA, app stores)          |
| `social-preview-dark.png`, `-light.png`                  | 1280×640, GitHub's social preview (with their `.svg` sources) |

The website's `favicon.ico` (16, 32, 48 px), `apple-touch-icon.png` (180 px),
`icon.svg` and `social-preview.png` (the dark one) are copies of this set, in
`apps/website/public/`.

Every Soundor lockup has the same viewBox height (136), so they render at the
same scale at the same pixel height. Tile: 108 units, with the brackets as the
family mark. Name: Space Grotesk SemiBold, 88 units, under a Medium “Soundor” line of 36 units.
Colours: ink `#10121A`, light `#F2F4F7`, accent orange `#FF5A1F`, and the orbits’ purple `#B8A3FF`, lime `#C4EC6F` and orange `#FF8F4D` (deeper shades on the light tile).
